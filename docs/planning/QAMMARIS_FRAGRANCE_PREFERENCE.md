## Profile and engine contract for PREF-02

Separate recommendation profile stores product identity, parser version, source fingerprint, detected attributes, per-attribute evidence, unknowns, review corrections and revisions. Exact explicit bilingual/typo/compound normalization only; deduplicate per note layer. Opaque terms and placeholders remain unknown. [Proposal dictionary](../../resources/data/fragrance-note-aliases.json) contains search groups, not verified scent families or interchangeable ingredients. Do not turn vanilla into a sweetness level or EDP/Extrait into longevity. Factual descriptions outrank notes inference; promotion, negation and source conflicts require review. Changed notes/descriptions invalidate the profile; dependent old overrides become review-needed, not silently retained.

Review placeholders, unknown terms, conflicts, verified identities across sizes and products used in acceptance. Corrections affect profiles only. Current catalog publication, active offer price/size, image and effective availability remain authoritative.

Initial versioned weights: aroma50, sweetness15, projection10, longevity10, usage context10, catalog gender5. Calibrate against training labels and freeze the accepted engine version before hold-out check/release. No AI or automatic feedback learning. “Any/unknown” answers contribute no weight. Missing attributes earn no points and never benefit from shrinking a denominator. Explicit aroma choices outrank a known favorite profile. Gender is light preference, Unisex stays eligible.

Only public/visible/unarchived products with valid single-offer price and sufficient aroma evidence are candidates. Exclude detected avoided characters before ranking; disclose incomplete evidence without allergy/ingredient-free claims. Rank by fit, then evidence completeness, Ready, lower price, stable ID; never substitute bestseller. Collapse sizes only by verified identity, never by identical notes. Max3 in-budget choices. Separate max1 alternative priced ≤110% only when fewer than3 main choices or better than the last main. Ready/Habis both eligible and labelled; Ready filtering does not require retesting. No irrelevant fill cards: sparse/empty results offer explicit budget/preference edits. Unknown taste yields “Pilihan awal untuk dieksplorasi” if contextual evidence supports it. Two evidence-based reasons plus limitations/compromises; no unvalidated percentages or performance promises.

## Website, results and feedback contract for PREF-03

Eight core screens: budget presets/custom rupiah/unlimited; usage (daily/office-study/casual/event-date/any); environment (AC/outdoors/mixed/any); max3 liked families/unknown; multiple avoided families/none-unknown; sweetness (light/medium/sweet/any); projection (close/medium/strong/unknown); longevity needs (not priority/few hours/all day/unknown). Optional gender (Pria/Wanita/any) and existing favorite search, both skippable. Simple families: citrus/segar, aquatic, green/herbal, fruit, floral, wood, gourmand, amber/resin, oud, leather/smoke, musk, powdery. Longevity answers are needs, not guaranteed product performance. Reject like/avoid conflicts before progressing. No personality/age proxy.

One question/screen, Indonesian Back/Next, clear progress, immediate options (no stagger), inactive panels removed from focus/accessibility tree. Draft answers survive Back/refresh in local browser for24h. Editable summary before server submit. Result shows authentic image/name/brand/size/current price/status/product URL, reasons/limits and loading/error/retry/few/empty/saved/expired states. Refresh preserves answers. Changes create a new result version so prior feedback stays linked. Show current price/status and recompute; never disclose no-longer-public products via old results.

Keep existing GET/POST quiz; new random-ID results and POST feedback under `/fragrance-quiz`. Safe anonymous browser cookie binds seven-day access; URL alone insufficient, no account/PII, noindex/private no-public-cache results. Hash browser tokens; never raw token/cookie/full request in logs. Store structured answers, question/engine versions, recommended IDs/internal scores/reasons/profile fingerprints. Anonymous answers/feedback retained without automatic purge.

Overall relevance: Sesuai / Sebagian sesuai / Kurang sesuai. Optional per-perfume: Menarik / Biasa saja / Kurang menarik plus structured aroma/price/availability/unfamiliar-product reasons. Not proof of smelling/liking scent. Re-submit updates same result feedback, no duplicates; rated IDs must belong to original result. Server validation, CSRF, browser rate limits10 quiz submits/minute and20 feedback/minute plus IP guard. No name/WhatsApp/location/free text requested. Existing admin access reviews issues, edits evidence/revisions, runs evaluation and reports feedback by product/engine. No new account system.
