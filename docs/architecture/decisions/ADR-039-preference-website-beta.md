# ADR-039 — explicit Owner-authorized preference beta

Date2026-10-10. Owner explicitly requests release for testing before independent quality acceptance. Implement the necessary PREF-03 website/feedback adapter then technical MySQL/CI/live checks; do not merge a disconnected backend and describe it as testable. This supersedes ADR037/038's pre-release human-quality gate **only for a labelled beta**, preserving pending reference/quality status and all avoid/budget/security/catalog rules. No final V1 accuracy acceptance is inferred.

Laravel/Blade native form with bounded local drafts, encrypted anonymous browser cookie and HMAC ownership, UUID results with seven-day access but no record purge, structured replay-safe feedback and existing admin reports/corrections. No identity collected. Private responses and rate/cookie middleware order are explicit; session CSRF retained. Original result snapshot never grants publication/price authority. Current visibility/offers reread and changed data disclosed; recompute writes new history. Database writes limited to four new recommendation/result tables and migration ledger; profiles require current preview and existing admin attribution. No new account, external AI or automatic feedback learning.

Flag defaultfalse; enable after candidate/migrations/profiles/CI checks. Roll back flag to legacy and retain all new tables/history. Device/human-quality limits remain reviewable and are not marked DONE by a beta release. [Evidence](../../verification/pref-03/README.md), [runbook](../../runbooks/FRAGRANCE_PREFERENCE_BETA.md).
